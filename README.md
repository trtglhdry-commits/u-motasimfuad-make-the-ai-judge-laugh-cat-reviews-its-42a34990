## Run it

```sh
node main.ts
```

Writes the review to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the directory). Deterministic: the same 131-character line on every run, enforced against the competition's 1–200 character, single-line gate in code.
